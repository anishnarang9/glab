# P2 First Recording Session

P2 (C6 incomplete, implanted 3 months ago) came in for their first extended recording session today.

**Array quality:** excellent. 89/96 channels have good SNR (>4:1), 71 show clear single-unit activity. Much better than P1 at 3 months post-implant — might be a surgical improvement or just individual variation.

**Task:** motor imagery of 8 grasp types, 10 trials each. No actual movement (incomplete injury means partial movement possible but we want imagery data first).

**What we saw:**
- Clear modulation during imagined grasps in ~40 units
- Imagined precision grip vs. power grasp are separable with linear SVM: 74% accuracy (chance = 50% for 2-way)
- Surprisingly, some units in PMd (second array) fire more reliably than M1 units for some conditions

**P2 is remarkable:** they figured out our task faster than P1 did at the same stage. Very motivated. Already asking about the timeline for real-time control.

**Plan for next session:** add attempted movement trials alongside imagery, compare population geometry. Test whether the rotational dynamics we see in P1 are present in imagery as well.

Agent helped me organize the session notes and flag the PMd finding as potentially important.
