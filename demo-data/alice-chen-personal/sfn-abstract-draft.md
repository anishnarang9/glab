# SfN 2026 Abstract Draft

**Title:** Cross-subject decoding of visual object categories via hyperalignment to a CLIP-aligned shared neural space

**Authors:** Alice Chen, David Kim, [PI name]

**Abstract (draft):**
Decoding visual information from fMRI signals across subjects remains challenging due to individual differences in functional neuroanatomy. We collected 7T fMRI data from 8 subjects viewing 50 visual object categories and tested whether a CLIP-derived shared representational space could serve as a common alignment target for cross-subject decoding. Using Procrustes hyperalignment, we achieved 67% accuracy on 50-way classification in left-out subjects (chance = 2%, within-subject ceiling = 79%). Critically, alignment to CLIP's mid-layer representations outperformed alignment to ImageNet-trained ViT (67% vs. 54%), suggesting that language-grounded visual representations provide a more universal cortical alignment target. These results have implications for designing brain-computer interfaces that generalize across users without extensive individual calibration.
